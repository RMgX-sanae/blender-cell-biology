# 60 个常用过程的动画配方

配方提供分镜、约束和实现方向，不代表 60 个过程已经自动生成或逐项实测。具体物种/组分/速率需要在项目中核对原始资料；S10 Reactome 可用于寻找事件与其原始论文。优先读相关行，再展开核心过程详解。除标记“模板”的条目外，均需 agent 编写场景脚本。下述“增长/移动”指示意动画，除非输入了实验轨迹或经验证的模拟。

若要求任一过程从上游到下游完整展开，使用 [机制深度规范](mechanistic-depth.md)，先补足输入、许可、原料、执行、产物、终止及回收事件。肌动蛋白已有 [Arp2/3 与 formin 两套全周期计划](actin-full-cycle.md)；它们与以下局部可执行示例的状态分别报告。

## A. 遗传信息（01–12）

| ID / 过程 | 对象与事件顺序 | Blender 实施 / 验收重点 |
|---|---|---|
| 01 DNA 复制（精细复制叉示例） | 亲代双链→解旋→前导链连续/后随链片段合成→引物处理与连接 | `build_replication_scene.py` 实现局部叉推进、完整单位、两种延伸与引物符号；未实现引物处理/连接。P07–P08 |
| 02 复制起始与双向复制泡 | 特定 origin→许可/激活（真核）→两复制叉相背推进 | 两组 fork rigs；按物种建立复制子，不把细菌单 origin 通用于人类染色体 |
| 03 DNA 损伤与修复 | 指定损伤→识别→加工→补合成→连接 | 选 BER/NER/MMR/HR/NHEJ 中一个，不能混成一套万能剪切；保存断裂与末端身份 |

| 05 真核转录（精细加入示例） | 启始复合物→转录泡→延伸→终止 | `build_transcription_scene.py` 重构一次 C 加入；`extend_transcription_scene.py` 放慢并接转位及 U 加入。5FLM 支持第一轮产物端点，第二轮为教学重构；不涵盖全部阶段或真实催化轨迹。P09/P13/P20/P22 |
| 06 细菌转录–翻译耦联 | RNA 聚合酶出 RNA→核糖体装载→延伸 | 无核膜；转录与翻译可同时进行，但不能套到核内真核 mRNA |

| 10 翻译（精细底物循环示例） | 起始→tRNA 进入/肽键形成/转位→终止 | `build_translation_scene.py` 示意进入、短肽转移及三核苷酸转位；不含因子、混合态和起始/终止。mRNA 5′→3′，肽 N→C |

| 12 染色质重塑/核小体滑动 | DNA–组蛋白复合→因子结合→位置/可及性变化 | 固定 DNA 连续性；可及性不等于转录已经发生，也不等于 TF 已结合 |

## B. 分裂、骨架与运动（13–24）

| ID / 过程 | 对象与事件顺序 | Blender 实施 / 验收重点 |
|---|---|---|
| 13 动物细胞有丝分裂（模板） | 凝缩/核膜变化→纺锤体连接→排列→姐妹分离→核重建 | 模板从中期起；完整版本用事件表和染色体 ID，不能在中期复制 DNA。P03/P06 |
| 14 动物胞质分裂（模板） | 收缩环→分裂沟→中体→膜切断 | 连续形变+明确 abscission 拓扑切换；最终货物/染色体计数不能凭空翻倍 |
| 15 减数分裂 | 同源配对/交换→同源体分离→姐妹分离 | 两轮分裂，一轮复制；交叉与姐妹黏连分开；不要把两次有丝分裂当减数 |
| 16 植物胞质分裂 | 成膜体指导囊泡→细胞板扩展→接入母细胞壁/膜 | 从中心向外扩展板；不使用动物式收缩沟作为主机制 |
| 17 细菌二分裂 | 复制/分配→分裂位点→隔膜生长→分离 | 按具体菌种建包膜层和 FtsZ 系统；无纺锤体和膜包裹细胞核 |
| 18 酵母出芽 | 极性建立→芽生长→核/细胞器分配→颈部分裂 | 母芽尺度与核膜行为核对物种，不能把芽当膜运输囊泡 |
| 19 微管动态不稳定 | 增长→灾变→缩短→拯救 | [可执行骨架模板](polymer-templates.md)：完整 αβ 二聚体、局部三原丝窗口，增长/灾变后缩短/恢复分开；不缩放单体或整管直径 |
| 20 肌动蛋白踏车/分支 | 成核→端部聚合/解聚→分支 | [可执行骨架模板](polymer-templates.md)：端部延伸/解聚、踏车、切断、退火、成束、CapZ 与 Arp2/3 子丝延伸；不含全部成核调控。固定亚基 ID，整丝平移不等于踏车 |
| 21 分子马达运输（模板） | 马达结合轨道→有向运动/停顿→卸载 | 连接 stalk 与 cargo；核对 kinesin/dynein/肌球蛋白家族方向；模板无步态/ATP 动力学 |
| 22 细胞迁移/趋化 | 前缘突出→黏附→收缩→尾部释放 | 胞体形状键+局部骨架动画；配体梯度与细胞感受分开，不能等同全细胞刚体平移 |
| 23 纤毛/鞭毛运动 | 轴丝马达滑移→受约束弯曲→波传播 | 骨架曲线按弧长形变保持长度近似；真核摆动与细菌旋转不能混用 |
| 24 肌节收缩 | Ca²⁺ 触发→横桥循环→细丝滑移→放松 | 保持粗/细肌丝长度，改变重叠；ATP 作用步骤核对体系，不把每根丝缩短 |

| 31 组成型分泌 | 载体→质膜融合→腔货物变胞外 | 胞内尾留在胞质面；融合后分泌蛋白从连通腔释放 |

## 五个核心过程怎样做成可信分镜

### 有丝分裂：先记录身份，再安排画面

对教学简化的 `2n=4`，G1 有 4 条染色体；复制后仍为 4 条、每条两姐妹。中期母细胞共有 8 条染色单体；后期姐妹分开成为子染色体，每侧得到 4 条。真实人类细胞模型若不是 46，必须标出简化数。

示意时间线可以是 0–20% 凝缩/前期，20–35% 核膜破裂与捕获，35–50% 中期对齐，50–75% 姐妹分离，75–100% 核重建/分裂。比例只服务讲解。不同生物的开放/封闭有丝分裂不同。先建立 chromosome IDs、sister pairing、kinetochore endpoint、spindle poles，再动画位置；不能靠颜色猜哪个进入了哪个子细胞。

核膜消失应当是所选体系的拆解示意；中期不要仍画一层完整阻隔纺锤体的核膜。微管在动粒处终止，而非穿过染色体中心。后期阶段更换 X 形资产时保留实体 ID；不要把每个 X 完整复制到两边。脚本模板只覆盖中期以后的压缩示意。

### DNA 复制：固定四条方向标记

画出亲代两条链 5′/3′，确定 fork 向哪边移动。前导新链向复制叉连续增长；后随链的每个 Okazaki 片段依旧从 5′ 向 3′ 增长，但在局部表示中朝离开复制叉的方向。引物先存在，然后从它的 3′ 端延长；最后处理引物并连接切口。不得让其中一条 DNA 按 3′→5′ 合成。

建模可以拆成：初始双螺旋、展开模板、聚合酶 rig、新链曲线分段、primer、ligase 的固定事件。需要复制泡时设置两个对称但方向定义独立的 fork。半保留复制的最终两套双链各带一条亲代链；用颜色和身份检查，而非只看末端有两根绳。

旧白模采用固定局部叉。精细 `build_replication_scene.py` 增加叉推进、完整核苷酸、方向标注和引物符号，但未模拟酶化学或完整 lagging-strand loop，也未做引物去除/连接。若用户要“完整复制”，必须补这些镜头并重新验证。

### 转录：3′ 端在活性中心

在 template strand 上定义 3′→5′ 读取方向。聚合酶局部打开 DNA，RNA 与模板互补并以 5′→3′ 增长；自由的 5′ 端先从酶中出来。离开聚合酶后 DNA 复性。可使用局部 bubble 的形状键、nucleic-acid 曲线和酶刚体；不要将整段 DNA 两条链永久剥开。

真核 mRNA 镜头若继续到翻译，先处理核输出和项目关注的 RNA 加工；原核版本可以演示耦联。终止不必用聚合酶“撞墙”；选择对应终止机制。精细加入示例用独立的底物/产物端点和示意运动，不包含起始、转位、整段延伸或终止；构建体中的 3′去氧阻断、非水解类似物和缺失末端必须先核对。

### 翻译：把化学步骤与物理位移分开

确定物种与核糖体结构，mRNA 5′→3′ 穿过小亚基。详细循环可拆为：带氨基酸 tRNA 在 A 位点被选择；P 位点肽链转移到 A 位点 tRNA；转位使 tRNA 身份在 A/P/E 间转换；空 tRNA 离开。肽 N 端先出现，新增残基加在 C 端。起始时不能机械照搬延伸 A 位点装载。

为避免双重移动，只固定核糖体或 mRNA 之一再定义相对运动；nascent chain 的 C 端经 tRNA 留在核糖体内部的催化中心附近，N 端经出口隧道显露。用重采样曲线释放 N 端，不把 C 端锚在隧道外口。终止由释放因子识别 stop codon 的机制表示，不画“终止密码子对应的普通 tRNA”。精细底物示例仅使用短肽符号，尚未显示出口隧道中的长肽、延伸因子、混合态或完整循环，见 [production-workflow.md](production-workflow.md)。

### 囊泡完整循环：拓扑切换是重点

将 compartment graph 写出来：胞外/腔侧、胞质侧、供体膜、受体膜。出芽时供体腔与芽腔相通；scission 后隔离；运输期间货物留在腔内；对接并未连通；fusion pore 开放后才允许腔内容物交换。跨膜受体的胞质尾在这些阶段一直朝胞质。

同拓扑的形变用 shape keys；出芽分离和融合孔属于拓扑变化，使用预建阶段网格、缓存或经过检查的重网格。不要尝试把顶点数不同的两阶段硬塞进同一组 shape keys。遮挡下切换资产可以作为教学简化，但要检查前后帧、边缘、货物位置和方向。

运输路径用 arc-length 参数化维持所需速度；跟随朝向只决定模型姿态，不应改变受体内外翻转。模板只展示已分离囊泡沿微管运动；完整内吞/出胞另做分镜。
