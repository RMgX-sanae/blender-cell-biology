# 按任务选择入口与验证范围

先确定交付是静态结构、局部动作还是完整过程，再选下面的入口。新蛋白或新机制接着读 [workflow-transfer.md](workflow-transfer.md)，只替换必要的数据和科学规则；已有源构象、反应位点或路径不会因更换名称而自动适用。

## 怎样读验证状态

- **独立重建**：指定案例曾从解压后的 skill 和原始输入重建，并检查所列工程、图片或视频；只覆盖该案例、版本和输出条件。
- **局部验证**：所列配置、阶段或显示方法已实际检查，不意味着整个生物过程或全部风格组合通过。
- **既有片段/模型**：已有生成入口和制作样例；该段的范围较窄，此次没有重新完整验收。
- **配方**：说明如何制作，仍需项目实现。不得将其计为已完成动画。

这些状态描述软件与交付证据。来源结构、推定运动和教学简化另按各案例说明标注；独立重建也不等于实验动力学验证。以下整理依据截至 2026-11-06 的制作与复验记录；机制检查涉及 PTP1B 的共价中间体、共用分子序列显示、高对比配色和转录的跨阶段身份，未重做全部旧影片。后续改动影响的案例应重新验证，不能沿用旧状态作保证。

开发验证默认使用 [关键帧与短预览](review-and-retention.md)：`render_saved.py` 支持帧范围/步长和临时采样覆盖，`encode_review.py` 保持抽样时点的原速间隔。已在分子动画的 Eevee 关键帧/短片和细胞静态场景的 Cycles 单帧上实测；无需为每次迁移完整渲染视频。中间帧按用户授权清理后，历史检查结论保留，原帧是否仍在磁盘上另以清理记录为准。

## 已有验证记录摘要

下列是上述状态的依据摘要，不是要求每次任务都重跑的检查清单。完整制作记录和生成媒体保留在项目目录，skill 只分发生成方法。用户对旧片段的满意反馈不自动替代新项目验收。

- **配置迁移**：MDM2/p53 以项目自己的 ID 和 JSON 调用原生成器；818 个原子、193 个含接缝时点的保存工程检查和关键帧复核。不新增完整影片的验证声明。
- **反应身份共用**：PKA、Ras 水解、K63 接入同一账本后，22 个 NPZ 中的 107 个数组保持不变；六类错误账本被拒绝。AMSH-LP 后续复用该入口并单独定义水氧和断键/成键。
- **反应阶段交接**：同一账本检查器核对固定原子集合的阶段序列和独立总反应。最初 23 原子图原型的身份/中间键/净映射反例仍保留；PTP1B 后续另行资格审查并扩展到 2,482 个重原子的几何与显示，不能把前者当作后者的证明。
- **共价中间体与显示迁移**：PTP1B 从解包脚本及公开原始缓存重建，23 个既有数组相同，五张深色关键帧逐像素一致；625 个保存姿态、标记和字幕通过。26 秒深色影片 624 帧全部解码、12 张编码帧与原图比较，五个关键时点实际看图；浅色初态和终态另看图。原生播放因电脑锁屏未执行。AMSH-LP 用同一显示入口复核 721 个姿态、2,569 个原子及一个渲染时点，未重做其影片。八类反例覆盖源文件、缓存、单位、字幕、次序、途中旋转、非均匀缩放和显示边；Pi 释放仍未通过本次路径筛查，过程目录状态不外推。
- **局部特写的可读性修订**：用户否定上述 PTP1B 旧骨架构图后，当前默认改为 Cys215/Gln262、底物 Tyr992 和反应基团；用户认可了新关键帧的信息量。重新解包建景并复核全部 625 个姿态；五张重建关键帧中四张完全一致，另一张仅一个像素有最大 1/255 通道差异。新版影片 624 帧完整解码，15 张编码帧与源图比较，六张关键编码帧实际看图，浅色两端另查。此次改变显示选择，未扩大化学机制或实时播放的验证范围。
- **完整 actin 案例**：21 章来源资产、保存几何、字体与路径重建；两条影片完整解码并抽查实际画面。适用范围仍为各章声明的教学情境。
- **K63→AMSH-LP**：重新准备的 24 个数组与复核项目一致；721 个准备姿态、两种风格各 720 个保存帧、六个反例和 30 秒完整视频检查；来源几何及远端刚体释放的失败案例没有被略过。
