# 细胞与细胞器建模配方

这是形态与拓扑的建模入口。具体物种、细胞类型、状态和尺寸由项目资料决定；表内描述不授权填入未经核实的数值。全细胞低细节代理不能直接升级为纳米结构证据。资料入口见 sources-and-evidence.md：S01–S05、P03–P05。

## 20 类细胞的差异

| 类型 | 应优先识别的结构 | Blender 实现与检查 |
|---|---|---|
| 一般动物间期细胞 | 质膜、核、ER/Golgi、线粒体、骨架 | 用参考轮廓变形网格；培养贴壁细胞通常不能用悬浮球形代替 |
| 极性上皮细胞 | 顶端/基底侧、细胞连接、基底膜 | 命名 apical/basolateral 面域；受体按面域采样；组织接触面不随机散放微绒毛 |
| 肠吸收细胞 | 顶端刷状缘、基底核区、连接复合体 | 微绒毛用有方向实例，内部为 actin 束；不是运动纤毛 |
| 杯状细胞 | 顶端黏液分泌颗粒、压向基底的核 | 颗粒保留包膜和顶端出胞方向；数量/大小参考分化状态 |
| 成纤维细胞 | 展平/梭形、应力纤维、局部黏着 | 曲线构成纤维，实例化黏着组件；形态依基底和迁移状态 |
| 神经元 | 胞体、树突、轴突、末梢 | 树状曲线 sweep、局部 spine 实例；轴突/树突的微管方向和核糖体分布不能混用 |
| 星形胶质细胞 | 多分支突起、局部端足 | 从分割/参考轨迹建立分支；不要凭二维投影宣称完整三维连接 |
| 骨骼肌纤维 | 多核、肌原纤维、肌节、周边核 | 周期实例化肌节；避免将所有肌细胞都设为单核短梭形 |
| 心肌细胞 | 分支、闰盘、肌节、丰富线粒体 | 端部连接专门建模；不直接照搬骨骼肌核数和排列 |
| 成熟哺乳动物红细胞 | 双凹盘、无核及多数细胞器 | 用径向截面旋转/形状键；不能添加正常细胞核/线粒体；其他物种另查 |
| 血小板 | 小型无核细胞碎片、颗粒、活化伪足 | 分开静息与活化状态；不制作其有丝分裂 |
| 静息 T/B 淋巴细胞 | 核占比大、相对少胞质 | 受体依细胞身份/活化状态选取；TCR 与 BCR 不能当作同一表面组件 |
| 中性粒细胞 | 分叶核、颗粒、运动伪足 | 核叶用连续连接建模；不能把每叶标为独立细胞核 |
| 单核细胞/巨噬细胞 | 核形、吞噬杯、内吞/溶酶体系统 | 细胞身份与状态分开；吞噬物留在有边界的 compartment |
| 浆细胞 | 发达粗 ER、偏位核、分泌装置 | ER 面片网络、胞质侧核糖体；抗体合成/分泌沿正确拓扑 |
| 脂肪细胞 | 脂滴、受压胞质与核 | 区分白/棕脂肪形态；脂滴是单分子层，不是双层膜囊泡 |
| 植物叶肉细胞 | 细胞壁、质膜、大液泡、叶绿体 | 壁在膜外；叶绿体的双层包膜/类囊体分开；不要加入动物式分裂沟 |
| 植物根细胞 | 壁、液泡、塑体，通常不照搬叶绿体丰富形态 | 按根组织/分化位置建模；细胞板与成膜体的配方见动画表 |
| 芽殖酵母 | 细胞壁、核、液泡、芽颈 | 核分裂方式与哺乳动物不同；分裂时不能自动删除核膜 |
| 细菌（杆/球/弯曲型） | 核区、70S 核糖体、包膜/细胞壁 | 无膜包裹的真核细胞核；按革兰阴/阳或具体种类设置包膜，不把所有细菌加双膜 |

生殖细胞、干细胞、肿瘤细胞不是固定形状模板：按物种、发育/分化阶段、组织和病理条件重新找参考。病毒可作为货物/病原颗粒，不能称为一种细胞。

## 27 个结构组件

| 组件 | 必须保持的几何或拓扑 | 建模方法、常见失误 |
|---|---|---|
| 质膜 | 一个双层膜分隔胞外/胞质 | 远景薄壳，近景双叶+脂质实例；“双层”不是两张无厚度的无关板 |
| 糖萼/糖链 | 朝腔面/胞外的分支链 | 从有证据的糖基位点建立曲线；不用等长毛发替代真实糖链并声称原子精度 |
| 核膜 | 内外核膜、核周腔、孔处连续；外膜与 ER 连通 | 双壳+真实孔/切口；只贴黑点不能表现核孔通道 |
| 核孔复合体 | 跨核膜的有方向通道 | 环形重复实例；详细对称性/组分由所选结构决定 |
| 核纤层 | 核膜核质侧 | 薄网格；不能放到胞质侧 |
| 染色质/核小体 | DNA 与蛋白复合；状态依细胞周期 | 远景密度/曲线，近景结构数据；不要把间期染色质全画成 X |
| 核仁 | 无膜结构，分区按数据 | 多相网格/体积；勿包一层脂膜 |
| 核斑/凝聚体 | 无膜、动态富集 | 软边界或明确的分区示意；不能把液滴外观当作相分离实验结论 |
| 粗面 ER | 连续腔与膜片/管网络；核糖体在胞质面 | 有壁厚 sweep 与连接；装饰散珠不能代替正确的膜侧 |
| 光面 ER | 连续管网，可与 ER 膜片连接 | 曲线网络转网格、分支合并；避免相交而不连通 |
| Golgi | 有 cis/trans 极性的一组膜囊 | 弯曲面片加边缘、分开 cisternae；不是实心饼或所有层相通 |
| ER–Golgi 中间区 | 特定载体/管泡结构 | 按分镜简化并标注，不机械画成一串同直径球 |
| 线粒体 | 外膜、内膜、膜间隙、基质 | 两层封闭边界；总览代理需明确内部未解析 |
| 线粒体嵴 | 内膜折叠与嵴连接部；嵴腔属膜间隙侧 | 可编辑连接网格；孤立“薯片”只可作远景代理，不能充当真实嵴拓扑 |
| 叶绿体 | 双膜包膜、基质、类囊体腔 | 类囊体膜为独立系统；连接关系参考物种与切片/断层数据 |
| 早/晚内体 | 膜边界与成熟状态、管状分选区 | 形态/标记不同步推断；EEA1 共定位不是摄取量，也非所有内体身份 |
| 多泡体 | 胞内内体内含腔内小囊泡 | 内向出芽方向正确；小囊泡不能放到胞质侧后仍标为 ILV |
| 溶酶体 | 单膜、有腔内容物 | 酸度用注释/示意编码；不是从颜色读出的测量 |
| 过氧化物酶体 | 单膜、内容与导入机制 | 不照搬线粒体双膜；晶核不是所有物种/细胞的必备结构 |
| 脂滴 | 中性脂核心、磷脂单分子层 | 表层只设单层；ER 连接需要具体阶段证据 |
| 自噬体 | 闭合双膜包裹胞质货物 | 先开口隔离膜再闭合；与溶酶体融合是后续事件 |
| 常规运输囊泡 | 一个脂双层膜边界、膜蛋白朝向及腔内货物 | cargo 与囊泡共同父级；出芽前后保持腔/胞质关系 |
| 微管 | 中空管、极性；常见 13 原丝但并非所有体系固定 | 远景曲线、近景带极性的二聚体阵列；马达不能无说明反向 |
| 微丝/肌动蛋白 | 双螺旋聚合物、正负端、分支条件 | curve+实例；长度变化、分支角与浓度不能只为美观随意设定 |
| 中间丝 | 纤维网络，不按 actin/microtubule 极性马达设定 | 网状曲线+组织特异标记；勿自动增加正/负端运输 |
| 中心体/中心粒 | 动物细胞相关组织中心；细胞/阶段依赖 | 多重重复结构；不能为所有植物体细胞添加一对中心粒 |
| 纤毛/鞭毛/微绒毛 | 轴丝与基体，或 actin 束的不同结构 | 常见 9+2/9+0 不是无例外规则；微绒毛不可套用纤毛轴丝 |

## 尺度与视角

全细胞通常跨微米，膜/蛋白跨纳米。先从来源取尺度，建立 `meters_per_blender_unit`；PDB Å → m 为 ×1e-10，nm → m 为 ×1e-9，µm → m 为 ×1e-6。不要仅设置 `scene.unit_settings.scale_length` 就认为已经转换了网格坐标。

若同镜头无法看清受体，采用局部放大/切换镜头；或明确标注“分子尺寸放大、非统一比例”。不为未定标的教学场景加看似精确的比例尺。正交相机便于比例比较；透视相机的屏幕长度依深度变化。

连续膜外壳的教学开口必须称 cutaway，边缘不能被误读成自然破口；用轮廓或局部薄壳分清膜面和腔。到了分子尺度，按 [section-views.md](section-views.md) 展示前后不同的完整单体、隐藏完整遮挡物，不直接切开脂质、蛋白或核酸，也不用实心板填补脂双层。
