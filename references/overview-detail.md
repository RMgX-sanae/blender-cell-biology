# 从总览进入同一对象的特写

先在总览成图里选一处能认出的结构，再选一处在放大后还看得到的邻居。细胞可选标记分叉和后方核区，膜面上可选一个完整受体和它左侧的另一拷贝。只在总览的目标外围放四个短角标，中心留空。在特写中检查两处的方位、轮廓和语义色。

## 从同一保存工程生成两个镜头

在项目的场景说明里加上 `view_handoff`。下面的坐标来自既有单细胞工程。换工程时，从自己的总览成图重新点选。坐标从画面左上角起算，横向取像素位置除以图宽，纵向取像素位置除以图高。

```json
{
  "view_handoff": {
    "entity": "核区上方的线粒体标记分叉",
    "focus": {"object": "Source structure", "at": [0.4328125, 0.30875]},
    "neighbors": [{"object": "Source dna", "at": [0.4765625, 0.37375]}],
    "zoom": 2.35,
    "locator_radius": 0.044,
    "scale_basis": "同一标本的显示坐标，绝对长度未标定"
  }
}
```

```bash
"$BLENDER" -b "$PROJECT/scene.blend" --python-exit-code 1 \
  --python "$SKILL/scripts/build_linked_views.py" -- \
  --brief "$PROJECT/scene-brief.json" --output "$PROJECT/views"
```

每个点可用一个具体网格的 `object`，也可用一组网格的 `collection`。多个受体外观相似时，同时填写两者，射线会检查集合里最靠近相机的命中对象是否就是指定实例。半透明外壳后方的对象可单独点选。重开后用成图核对实际遮挡。`locator_radius` 是从角标中心到方框边的距离，占图像短边的比例。选到恰好围住目标轮廓的大小。需要某个动画时刻时可加整数 `frame`，默认使用工程保存时的时刻。

输出目录含 `overview.blend`、`detail.blend` 和 `handoff.json`。两个工程都停在同一时刻。特写沿用观察方向并重新渲染场景。记录包括源文件哈希、对象与实例身份、命中坐标及法向、材质、邻居和两个镜头里的投影位置。`zoom` 表示相机视野的倍率，物理尺度依据写在 `scale_basis` 中。两个工程的灯光、景深和合成可分别调整。重开工程时可按原流程用 `render_saved.py --review-brief` 抽帧。用 `--compositor` 切换已有预设时，角标会接到所选分支的输出上。教学镜头选择能保留必要背景与标签的分支。

这条入口适用于 Blender 5.x 中正交或透视单相机的完整画幅，以及场景中可单独寻址的网格。点选前先还原裁切、拼版或会移动像素的后期变形。几何节点或集合实例需先有可核对的具体对象身份。总览角标在最终合成图上检查，特写里应能认出所选邻居。两张静帧只说明这个时刻的对应。跟随运动的镜头还要验证中间帧。

## 更换几何表示或数据来源

同一条蛋白或核酸链可以在总览中显示包络面，在特写中显示按重原子坐标放置的空间填充球。在已有的 `view_handoff` 中增设 `detail_spacefill`。用 `asset_dir` 指向制作该总览时的分子资产目录，路径相对于场景说明文件。用 `manifest_sha256` 填入上游建场记录中的资产清单指纹。旧清单未收录各链指纹时，再用 `chain_sha256` 填入上游保存的目标链 NPZ 指纹。受体工程分别可以从 `preparation.source_manifest_sha256` 和 `preparation.chain_hashes` 读取。

照常运行上述命令。特写仅替换点中的具体链拷贝，保留同一个 Blender 对象、变换和链身份材质。其它亚基与同链的重复拷贝继续用原来的表示。入口支持能和准备网格逐点逐面对应的单材质包络面，允许平滑显示以及等比例场景缩放。项目若用顶点属性着色，先明确这些属性在原子上的含义。

在特写网格中，顶点就是原子中心。`source_atom_row` 给出从零开始的原始准备行号，`source_residue_number` 给出残基号。`handoff.json` 记录离总览表面命中点最近的原子、二者的距离、这个原子在特写中的位置和使用的显示半径。行号需与链文件指纹配对。插入码未记录时保持未知。最近的中心是空间参照，一个包络面点本身不能确定化学接触或功能位点。保留原有角标和相机验收，重开特写后抽看变更的这一帧即可。

- 同一套数据从分割表面换为另一种显示，或从分子表面换成原子、骨架时，用原始坐标、链与残基身份或已知配准变换传递位置。重新定位新网格里的标志，保存两种表示的对应关系。核对分布在不同方向的共同标志及膜侧或手性，换网格后重新核对面编号。
- 全细胞标记只能定位到某区域时，后续另有来源的典型细胞器可用单独镜头展示。用一句必要的转场文字或解说交代“这里用典型结构说明内部”，在项目记录分别列出两个来源和各自尺度。在总览中保留区域线索，在特写中展示新来源确实支持的细节。
